# Stack-Based Expression Evaluator

**Course:** DCOMP320 – Data Structures and Algorithms
**Assignment:** Stacks Implementation (Individual, 10%)
**Institution:** Limkokwing University of Creative Technology, Sierra Leone

## Description
A Python program that reads mathematical expressions from `input.txt`, evaluates each
one using a stack-based algorithm, and writes the results to `output.txt`.

## Files
| File | Purpose |
|------|---------|
| `expression_evaluator.py` | Source code (Stack class, evaluator, file processing) |
| `input.txt` | Sample input expressions |
| `output.txt` | Output generated by the program |
| `README.md` | This document |

## Requirements
Python 3.6 or later. No external libraries are needed.

## How to Run
1. Put `expression_evaluator.py` and `input.txt` in the same folder.
2. Open a terminal in that folder and run:
   ```
   python expression_evaluator.py
   ```
3. The results are written to `output.txt`.

The program looks for `input.txt` in the folder you run it from, then in the folder
containing the program. `output.txt` is created in the same folder as `input.txt`.
If `input.txt` cannot be found, a clear message is shown.

## Input File Structure
- One mathematical expression per line.
- Expressions are separated by a line containing only dashes (e.g. `-----`).
- Spaces between numbers and operators are optional.
- Files saved by Notepad/Word are accepted (hidden BOM, Windows line endings, `×`, `÷` and long dashes are handled).

```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output File Structure
- One result per line, in the same order as the input.
- The same separator lines are kept between results.
- Whole-number results are printed without decimals (`13`, not `13.0`).

```
13
-----
16
-----
-10
```

## Supported Features
- Operators: `+`  `-`  `*`  `/`
- Parentheses, including nesting
- Operator precedence (`*` and `/` before `+` and `-`) and left-to-right associativity
- Decimal numbers (e.g. `2.5 * 4`) and unary minus (e.g. `-3 + 5`, `4 - -2`)

## Error Handling
An invalid expression does not stop the program; an error message is written on that line:
`Error: division by zero`, `Error: mismatched parentheses`, `Error: invalid expression`,
or `Error: invalid character 'x'`.

## Assumptions and Limitations
- Separator lines consist only of dashes (two or more).
- Blank lines in the input are ignored.
- Each expression must fit on a single line.
- Supports only `+ - * /`; powers, modulus and functions are not supported.
- Division always gives a decimal result (`10 / 4` = `2.5`); results with more than
  4 decimal places are rounded to 4.
- The second sample result is `16` ((8/4) + 7*2 = 2 + 14). The result `17` shown in the
  assignment sheet's example output does not match this expression.
